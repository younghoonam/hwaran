## Hwaran Headlamp

This project is a dynamic and interactive product showcase that provides 3D visualization to enhance user engagement and understanding. By scrolling, it provides an immersive experience by showcasing the product’s form and key features through fluid, interactive views. Users can explore functionality demonstrations with simulations and animations, gaining a clearer understanding of how the product works. Animated visual instructions guide users intuitively, highlighting controls and features for seamless interaction. The showcase also features product variation switching, allowing users to explore different options. Through interactive storytelling and engaging visuals, this experience enhances product appeal and customer engagement.

- Headlamp was designed and 3D modeled with Rhino3D
- 3D model was imported and displayed with THREE.js
- Developed a scroll animation keyframe system of position and quaternion to transform the 3D model
- Tween.js was used to animate lights and buttons of the product
